# snow-countdown-calendar

A countdown calendar with a live timer — tap a day and draw an ✕ to cross it off. 🗓️

Meet **Snow** ☃️, the little mascot who cheers you on as the days go by.

This project was made for a dear friend to encourage her and remind her that she's doing a great job, one day at a time. 💙
